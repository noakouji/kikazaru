# 要件：Kikazaru 配布サイト

## 誰が使うか

Kikazaru を受け取る人。多くは非エンジニア。
岡田が「こういうの作った」と話した相手が、URL を渡されて見にくる。

## 受け入れ条件

- [ ] 何のアプリか、スクロールせずに分かる
- [ ] 「自分に関係あるか」がすぐ判断できる（Sonos / Google Home を使っているか）
- [ ] ダウンロードボタンが迷わず押せる
- [ ] **初回起動でブロックされたときの対処が、手順どおりに書いてある**
- [ ] うまく動かないときの連絡先（Google フォーム）に迷わず辿り着く
- [ ] 「役に立ったらコーヒーおごって」が、押し付けがましくない位置にある
- [ ] スマートフォンで見ても崩れない（配布リンクは iPhone で開かれることが多い）

## 今回作らないもの

- ログイン、ユーザー登録
- 英語版（日本語のみ。アプリ本体は日英対応済み）
- 自動アップデート、バージョン履歴ページ
- アクセス解析

## 特に気をつけること

**初回起動の説明が、このサイトで一番大事。**
Apple Developer Program に入っていないため、ダウンロードした人は
「開発元を検証できません」で必ず止まる。ここで離脱すると全部無駄になる。
スクリーンショット付きで、右クリック→開く の手順を書く。

「AI が作ったっぽい」見た目を避ける。誇張した謳い文句を書かない。
ニッチであること、個人が趣味で作ったものであることを隠さない。
