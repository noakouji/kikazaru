# sonos-duck

マイクを使っている間だけ Sonos の音量を自動で下げる、macOS 用の常駐スクリプト。

音声入力（Aqua Voice 等のディクテーション、オンライン会議）を使うとき、スピーカーから流れる音楽が
マイクに回り込んで認識精度を落とす問題を解決する。ヘッドホンに切り替えず、スピーカー環境のまま使える。

```
マイクON  → 全ルームの音量をフェードダウン（約125ms）
マイクOFF → 0.4秒待って元の音量へフェードアップ（約126ms）
```

## なぜこの方式なのか

スピーカーの音がマイクに入る問題は、本来 AEC（音響エコーキャンセル）で消す。
しかし AEC は「スピーカーに送った信号」と「マイクに入った音」の時間を突き合わせて引き算する仕組みで、
AirPlay 経由の Sonos は遅延が 2 秒前後あり、しかも別クロックで動くため、この前提が崩れて機能しない。

そこで「消す」のをやめ、「喋っている間だけ鳴らさない」方式にした。
音楽体験を犠牲にせず、認識精度の問題だけを解消できる。

## 動作要件

- macOS（CoreAudio を直接参照）
- Python 3.9+（標準ライブラリのみ。追加インストール不要）
- Sonos S2 世代のスピーカー
- Sonos アプリで **UPnP が有効**（アカウント → プライバシーとセキュリティ → UPnP）
- 接続セキュリティの **Authentication は OFF**（初期値。ON にすると弾かれる）

## 使い方

```bash
python3 sonos_duck.py
```

起動すると SSDP で Sonos を自動検出し、制御対象を表示して待機する。
IP アドレスの設定は不要で、DHCP で変わっても追従する。

```
[18:05:28] 🎯 対象: リビング (192.168.1.10)
[18:05:28] 🎯 対象: 書斎 (192.168.1.11)
[18:05:31] 🔉 下げた  オフィス  28 → 8
[18:05:54] 🔊 戻した  オフィス  → 28
```

## 設定

`sonos_duck.py` 冒頭の定数で調整する。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `DUCK_RATIO` | `0.30` | 元の音量の何割まで下げるか |
| `DUCK_FLOOR` | `3` | 下げすぎ防止の下限 |
| `FADE_STEPS` | `5` | フェードの段数 |
| `POLL_SEC` | `0.05` | マイク状態の監視間隔 |
| `RELEASE_SEC` | `0.4` | 発話が途切れてから戻すまでの猶予 |

## 安全機構

音量を下げたまま取り残される事故を防ぐため、三重に対策している。

- 元の音量を `duck_state.json` に退避し、**次回起動時に自動復元**する
- `SIGINT` / `SIGTERM` を捕捉して復元してから終了する
- `atexit` でも復元する

強制終了（`kill -9`）で即死させた場合でも、再起動時に `duck_state.json` から復元されることを確認済み。

## 仕組み

### マイク検出

CoreAudio の `kAudioDevicePropertyDeviceIsRunningSomewhere` を既定の入力デバイスに対して監視する。
ホットキーをフックしないので、ディクテーションアプリ側のキー設定を変えても動作する。

### Sonos 制御

ポート 1400 の UPnP/SOAP を直接叩く（認証不要）。

`ZoneGroupTopology` で構成を取得し、**音量を個別に持つ可視メンバーだけ**を制御対象にする。
サブウーファーやサラウンドはサテライトとして親機に追従するため除外する。

グループ再生中は各機が自分の音量を持つので、全ルームを並列に処理する。
部屋数が増えても所要時間は伸びない。

## 実装上の注意（検証で判明）

- **`RampToVolume` はダッキングに使えない。** フェードイン用で、目標値を指定すると
  いったん 0 まで落ちてから目標値へ上がっていく
- **`RestoreVolumePriorToRamp` は HTTP 500 を返す**（Arc Ultra / ファーム 96.0-79160）
- **親機の `TransportState` は信用できない。** グループのメンバーが再生中でも
  親機が `STOPPED` を返すことがあるため、再生状態による分岐はしていない
- `GetZoneGroupState` の戻り値は **二重 XML エスケープ**されている

## tools/

開発時に使った診断スクリプト。単体で実行できる。

| ファイル | 用途 |
|---|---|
| `sonos_discover.py` | SSDP で Sonos を探す |
| `micprobe.py` | マイクの使用開始／終了をリアルタイム監視 |
| `outprobe.py` | 出力デバイスが音量・ミュート制御に対応しているか判定 |
| `gainlog.py` | 入力音量の変化を高頻度で記録 |
| `gainwatch.py` | 入力／出力音量とマイク状態を長時間記録（スリープ検出付き） |
